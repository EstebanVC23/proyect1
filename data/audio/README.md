# Archivos WAV para las pruebas

Esta carpeta está reservada para los audios propios que quieras analizar. La aplicación carga archivos desde cualquier carpeta del computador, por lo que no es obligatorio copiarlos aquí.

Para la actividad, reúne cinco fragmentos WAV cortos con una fuente legalmente autorizada:

1. Música clásica o barroca.
2. Metal.
3. Salsa **o** electrónica.
4. Música de cantina.
5. Reguetón.

Conviene utilizar fragmentos con duraciones parecidas y anotar título, intérprete/compositor, año y fuente en la ficha musical. No se incluyen canciones comerciales en el ZIP por derechos de autor.
